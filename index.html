Free channels

Notifications

Get reminded without opening the app — over free channels only. BookPilot sends no SMS itself: real texting needs a paid gateway, so it stays out (see below).

Browser notifications

Free. Shows a system notification on this device when you open BookPilot and reminders are due.

Phone push via ntfy.sh

Free. Install the ntfy app, subscribe to your topic, and push reminders to your phone from here.

Email reminders

Free via your own Gmail. Bookings can carry an email address; the included tool sends day-before reminders with your Gmail account — no password ever stored in the app.

Run node tools/send-reminders.js — setup takes a few minutes, documented in tools/README.md.

Why no built-in SMS? Sending real text messages requires a paid gateway (Twilio and similar charge per message). BookPilot stays free by using channels that cost nothing: browser notifications, ntfy.sh push, and your own Gmail.

Multi-device

Sync & transfer

BookPilot keeps everything in this browser. Move it to another device with a backup file or a QR code — no account, no cloud, nothing uploaded anywhere.

Backup file

Download a full backup, or restore one. Restoring replaces everything here — a backup of the current data downloads automatically first, so you can always go back.

Paste transfer text

Paste a transfer code (from a QR scan or copied transfer text) to import it.

QR transfer

Show a QR code of your booking data. On the other device: scan it with any QR reader app, copy the text, open BookPilot there, and paste it into the box above.

Tip: a QR code holds a few thousand characters. Large booking histories should use the backup file instead.
